# Domain Docs

How the engineering skills should consume this repo's domain documentation when exploring the codebase.

## Layout

This repo currently uses a **docs-first** domain-doc layout.

Current domain docs live under:

- `docs/lookbook/` for design-system and component behavior
- `docs/agents/` for agent operating guidance

## Before exploring, read these

- Relevant design-system docs in `docs/lookbook/` for the area you are touching.
- Relevant guidance in `docs/agents/` for workflow and conventions.

## Use existing terminology

When naming domain concepts in issues, refactor proposals, hypotheses, or tests, prefer terms already used in `docs/lookbook/` and component docs.

If a needed term is missing, add it to the relevant docs where that concept is defined.
